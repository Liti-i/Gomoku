# Gomoku
<img width="1598" height="892" alt="螢幕擷取畫面 2026-05-19 194411" src="https://github.com/user-attachments/assets/58b16d4c-d583-429d-929d-b3ee06c3daa8" />

•	模式切換：遊戲右側設有功能操作面板，玩家可在遊戲開始前點選「雙人對打」或「挑戰電腦」按鈕來切換對手。點選後系統會自動初始化棋盤狀態。
•	落子操作（精準校正）：遊戲遵從標準五子棋規則，棋子必須下在網格的「十字線交叉點」上。玩家不需極度精準地瞄準，滑鼠在交叉點附近點擊時，程式後台會自動進行數學幾何校正，將貓咪棋子完美坐在交叉點中心。

<img width="1593" height="881" alt="螢幕擷取畫面 2026-05-19 194305" src="https://github.com/user-attachments/assets/107feb25-58df-40a7-b19c-d4fc49cf66bb" />

•	獲勝條件：無論是黑貓（玩家/先手）或白貓（對手/電腦），只要在棋盤上的橫向、縱向、左斜、右斜任意一個軸線上，率先將五顆（或以上）相同顏色的貓咪連成一線，系統便會立即判定勝負，並彈出提示視窗與結算結果

•	特殊輔助功能（悔棋與重置）：
  • 悔棋功能：若不小心手滑下錯，可點擊右側功能區的「悔棋」按鈕，系統會依據歷史步數紀錄退回上一步
  • 重置棋桌：任何時候想要重新開局，點選「重置棋桌」即可瞬間清空全場棋盤，重置所有狀態變數
